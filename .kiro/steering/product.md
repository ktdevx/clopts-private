# Product Overview

> 2026-11-07 時点、ディスカバリー完了・実装未着手。本ファイルは roadmap.md と各 spec の brief.md から起こした「目指す姿」であり、project-foundation の実装後に `/kiro-steering` で同期する。

CLOpts は、C99 で書かれた外部依存ゼロのコマンドライン引数パーサライブラリである。呼び出し側が `static const` の宣言テーブルでサブコマンド・オプション・位置引数を書くだけで、解析・ヘルプ文面・エラーの 3 つが同じ宣言から決まる。出発点は [Monde](https://github.com/ktdevx/monde-private) の内部モジュール `cli_args` だが、そのまま抜き出すのではなく、コマンドライン引数を扱うソフトウェア一般のための設計に作り直す。

- 著作権者: The CLOpts Authors ／ ライセンス: MIT License
- 利用者: MSVC を含む複数のコンパイラで動く CLI ツールを C で書く開発者。`getopt` がなく外部ライブラリにも頼れない環境を想定する。

## Core Capabilities

- **宣言テーブルからの解析**: サブコマンドあり／なしの両構成、サブコマンド前のグローバルオプション、長いオプション（`--name`、`--name=value`）、短いオプション（`-o v`、`-ov`、`-abc` のまとめ書き）、`--` による終端、位置引数とオプションの混在。
- **値の種類と出所**: フラグ、カウントフラグ（`-vvv`）、単一値、区切り文字付きリスト値、`--no-<name>` による否定、既定値、環境変数フォールバック。優先順位は明示指定 > 環境変数 > 既定値で、値ごとに出所を判別できる。
- **構造化エラーと宣言検査**: 使い方の誤りは種別・該当コマンド・該当オプション・該当トークン・argv 添字を持つ構造体で返る。宣言の誤り（重複、予約名との衝突など）は使い方エラーと区別して返る。ライブラリは stdout / stderr に書かず、`exit` もしない。
- **宣言からの文面生成**: ヘルプ・使い方・バージョン・エラー文面を、書き込みコールバックに対して決定的な英語で生成する。`FILE*` 向けの便宜関数も持つ。
- **Windows での UTF-8**: `main` の argv を使わず、コマンドライン文字列を現行 MSVC CRT の規則で分割して UTF-8 に変換する。環境変数も UTF-8 で返す。

## Target Use Cases

- 4〜10 個程度のサブコマンドとそれぞれのオプションを持つ CLI ツール（Monde の `extract` / `init` / `update` / `translate` のような構成）。
- サブコマンドを持たない単純なフィルタ型ツール（`tool [options] FILE...`）。
- Windows / macOS / Linux に同じソースで配布し、日本語のファイル名など非 ASCII の引数を正しく受け取りたいツール。
- 利用側が独自の書式（`prog: error: ...`、色付け、ログへの転送）でエラーを表示したいツール。構造化エラーと書き込みコールバックがこれを支える。

## Value Proposition

- **宣言と挙動とヘルプが一致する**: オプションを追加・変更するとき、変えるのは宣言テーブルの 1 か所だけでよい。
- **利用側が表示と終了コードを決められる**: エラーは文字列ではなく構造体で返る。Monde で必要だった「ライブラリが付けた接頭辞を剥がして再整形する」処理が不要になる。
- **型で守られた値の参照**: 値はオプション記述子へのポインタで参照する。文字列キーの打ち間違いが黙って NULL になることがない。
- **取り込みやすい**: `add_subdirectory` / `FetchContent` / `find_package(CLOpts CONFIG)` のどれでも `target_link_libraries(app PRIVATE CLOpts::clopts)` だけで使え、利用側のビルド設定（CRT 種別、C 規格、警告）を汚さない。
- **依存ゼロ**: C 標準ライブラリと、Windows では kernel32 の API のみ。shell32 にも依存しない。

## Product Rules（挙動の既定）

- `--` 以降はすべて位置引数。`-` 単体は位置引数。
- サブコマンド名より前に置けるのはグローバルオプションだけ。サブコマンド以降はオプションと位置引数を自由に並べ替えられる。
- 長いオプションの前方一致による省略は行わない。大文字小文字は区別する。
- 単一値のオプションを繰り返すと後勝ち、リスト値は連結、フラグは重複を許す、カウントは上限でクランプする。
- `--help` / `-h` / `help <cmd>` / `--version` の要求は他の使い方エラーに優先し、状態として返る。
- 最初に見つけた使い方エラーだけを報告する。
- 値は文字列として返す。型変換・妥当性検査（整数、選択肢、範囲）は初版の境界外（roadmap.md の Future Phases を参照）。
