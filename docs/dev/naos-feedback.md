# Naos への要望（保守者向け）

この文書は、CLOpts のテストで使っているテストフレームワーク Naos について、足りない機能、困った挙動、CLOpts の側で入れた回避策を記録する。Naos の版の指定と更新の手順は [リリースの手順](release.md)（`docs/dev/release.md`）の「Naos の版の更新手順」を参照する。

Naos のリポジトリには Issue やコメントを作らない。要望はこの文書にだけ記録する。

## 規約

- 記録は追記だけを行う。新しい記録は「記録」の節の末尾に足し、番号は直前の記録の次の番号（`N-001`、`N-002`、...）にする。
- 既存の記録の本文は書き換えない、消さない。状況が変わったとき（Naos の版を更新して解決した、回避策を外した、要望を取り下げた）は、その記録の「状態」を更新し、記録の末尾に `- 更新（YYYY-MM-DD）: <何が変わったか>` の行を足す。
- 記録を書くときの Naos の版（`cmake/CloptsNaos.cmake` の `CLOPTS_NAOS_TAG`）を「対象」に書く。
- 回避策をコードに入れたときは、そのコードのコメントに記録の番号を書く（例: `/* Naos への要望 N-001 の回避策 */`）。

## 記録の書式

```markdown
### N-<番号>: <要望の要約（1 行）>

- 記録日: YYYY-MM-DD
- 状態: 未解決 | 解決済み（Naos vX.Y.Z） | 取り下げ
- 重要度: 高（テストが書けない・誤った結果になる） | 中（回避策が必要） | 低（不便）
- 対象: Naos vX.Y.Z（<機能、マクロ、CMake の関数などの名前>）
- 確度: 確認済み（再現の手順あり） | 推測（Naos のソースや文書からの読み取り）
- 背景: <CLOpts で何をしようとして、何が起きたか。再現の手順か、該当するテストのファイル>
- 要望: <Naos にどうなってほしいか>
- 現在の回避策: <CLOpts の側でしていること（ファイルとコメントの番号）。なければ「なし」>
```

## 記録

記録はまだない。
